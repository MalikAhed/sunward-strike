# Scoped n2 cloud review

Current procedural source was independently rendered through installed Mesa GLES with actual Three-generated programs and RGBA8 output. Twelve production shader programs compile/link; the reserved-keyword negative control is still rejected. Joined cluster geometry has 4,288 triangles, shared by 12 placements. Fresh atmosphere-only pixels improve crown scallops and retain smooth connected surfaces without old overlap seams.

Accepted as an incremental cloud-shape improvement. The four new appearance references still require connected painterly banks, broken wisps, richer azure and more lavender-blue underside structure. These are visibly unresolved; this is not full sky fidelity or a live browser pass.

See atmosphere-offline-rgba8.png and reproducible generator/renderer in this directory. Native n2 protected mesh/matrix/material bindings compare identically with diagnostic candidate-r2; source-only clouds/lights are excluded from runtime GLBs. Native and web tone mapping are distinct, so literal color parity is not claimed.
